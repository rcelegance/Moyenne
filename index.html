Installation (une seule fois)
  1. Sur le téléphone, ouvrez Chrome et connectez-vous au compte Google du CEG.
  2. Allez sur script.google.com (menu ⋮ → cochez « Version pour ordinateur »), puis « Nouveau projet ».
  3. Effacez ce qui est écrit, touchez « Copier le code » ci-dessous et collez-le. Touchez 💾 (Enregistrer).
  4. « Déployer » → « Nouveau déploiement » → ⚙ → « Application Web ». Exécuter en tant que : Moi. Qui a accès : Tout le monde. « Déployer ».
  5. « Autoriser l’accès » → choisissez le compte du CEG → « Paramètres avancés » → « Accéder à… » → « Autoriser ».
  6. Copiez l’URL de l’application Web (elle finit par /exec) et collez-la ci-dessous.

« Sauvegarder » crée un fichier avec toutes les classes, tous les élèves et toutes les notes, et vous laisse choisir où l’envoyer : choisissez « Drive » pour le garder dans Google Drive. « Importer » ajoute ce fichier dans cette version (rien n’est effacé). Utile pour passer de la version en ligne à la version hors ligne, ou pour garder une sauvegarde.

Réglage avancé : calcul de la moyenne

Règle actuelle : (moyenne des devoirs × 2 + composition × 3) ÷ 5. Les moyennes sont coupées après 2 chiffres (10,766 → 10,76).
